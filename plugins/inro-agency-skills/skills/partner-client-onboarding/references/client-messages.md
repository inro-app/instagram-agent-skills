# Client message and baseline note

## Message to send the client with the connect link

Adapt the wording to your own voice. Keep the four checks.

```
Hi [first name],

Here is the link to connect [Instagram handle] to the DM automation we set up for you:
[link]

Before you click:
1. Your Instagram needs to be a Business or Creator account. If it is a personal account,
   switch in the Instagram app first: Settings, Account type and tools,
   Switch to professional account.
2. Use a computer, not your phone. The login windows work better there.
3. Type your Instagram username, click Find Instagram account, then Authenticate with
   Instagram. Approve every permission it asks for. Skipping one breaks features later.
   If it says the account is already connected elsewhere, tell me before going further.
4. This only connects your Instagram. It does not give you access to our Inrō
   workspace.

[Managed link only:] Please do it in one go: if the page sits unfinished for about an hour,
just open the link again.

Reply here when it says the account is connected and we will take it from there.
```

If you set an automation template on a managed link and kept the notice on, the connect page tells the client that automation will be activated. Mention it in your message so it is not a surprise.
