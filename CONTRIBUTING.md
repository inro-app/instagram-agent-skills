# Contributing

Thanks for helping. Issues and pull requests are welcome.

- **Found something wrong?** Open an issue with the skill name, what you asked, what happened and what you expected. Leave out client names, handles and any data from a real account.
- **Improving a skill?** Open a pull request that changes one skill. Keep the `SKILL.md` frontmatter to `name`, `description`, `license`, `compatibility`, `metadata` and `allowed-tools`, so the skill still uploads to claude.ai.
- **Product changed?** If a skill uses a screen, field or limit that no longer matches Inrō, tell us in an issue, even without a fix.
- These skills are maintained by the Inrō team and reviewed before release. We may adapt your change before merging it.
- Never commit client data, exports, screenshots of client inboxes or tokens.

Questions: support@inroapp.com
